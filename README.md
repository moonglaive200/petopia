# Petopia 0.6.0 · 춘배와 집사의 이상한 하루

HTML/CSS/JavaScript로 실행되는 로컬 저장형 브라우저 게임. 서버 계정·온라인 랭킹은 없다. 이미지·폰트·음원은 저장소에서 로컬로 읽는다.

## 실행과 저장

```sh
cd /workspace/petopia
python -m http.server 8000
```

정적 호스팅은 저장소 루트를 배포하면 된다. 저장은 브라우저/주소별 localStorage에 보관되며 설정에서 JSON 내보내기·가져오기를 지원한다. 파일 실행과 웹 주소의 저장 공간은 다르다.

시작하기 → 슬롯 3개 중 선택 → 집사 이름 → 춘배 선택 → 마왕과의 전투·기억 상실·이별 → 비 오는 숲에서 첫 만남 → 춘배의 방. 오레오는 개발 중. 슬롯 삭제는 재확인하며 기존 이름·재화·소유 장비·관계를 보존한다. 기존 슬롯 강화는 현재 장착 장비의 개별 강화값으로 이관한다.

## 메뉴·달력·기록

메인은 2칸×4줄: 냥서바이벌 / 연애 / 힐링하기 / 주인 노동시키기 / 인플루언서냥 / 도박하기 / 펫마트 / 펫은행. 인벤토리 / 병원 / 잠자기 / 설정은 춘배의 방에만 표시한다. 가이드는 하루 한 개 랜덤으로 저장하며, 메뉴 이동·재접속으로 바뀌지 않는다. 모든 인게임 화면의 마지막에 같은 날짜별 냥생 기록창을 표시하고 내부 스크롤·최신 기록 갱신을 지원한다.

상태창은 레벨 / 공격·방어 / 행복도 / 유명세 / 골드·다이아 / 수입 보너스 6칸. 날짜는 `SPRING 1 (일) 📅`. 계절마다 28일, 봄·여름·가을·겨울 112일이 1년이다. 1일은 일요일, 토·일을 달력에 색으로 구분한다. 춘배 생일은 WINTER 27.

기력은 주인 기력 하나, 최대 100이며 당일 회복 불가. 기력 25 이하일 때만 잠자기로 다음 날 전환이 가능하다. 다음 날에는 전날 획득 골드·다이아·팬 변화·호감도 변화와 상세 정산을 보여준다. 현금 순변동은 별도 표시한다.

| 활동                          | 제한                                       |                         기력 |
| ----------------------------- | ------------------------------------------ | ---------------------------: |
| 냥서바이벌                    | 하루 1회, 행복도 20 이상                   |                           50 |

연애 메뉴에 들어가는 것만으로 기력을 쓰지 않는다. 실행 불가능한 행동은 기력·금화·아이템을 차감하지 않는다. 고백·프로포즈는 확률 실패도 실행된 행동이므로 기력과 다이아를 사용한다. 내 펫에게 츄르 먹이기는 기력0, 선물과 별도 하루1개.

## 장비 강화

공격 장비·방어 장비 각각10종. 펫마트는 구매·장착만 제공하며 기존 확정 강화 버튼은 삭제했다. 도박하기 → 장비 강화에서 장비별로 최대20강. 강화 시 제공된 긴장 효과음이 끝난 뒤 결과창·결과음을 표시한다. 연출 중 중복 입력을 차단하며 추첨·비용은 한 번만 저장한다. 음소거 시에도 약1.1초 연출 후 결과를 보여준다.

| 도전 단계 | 성공 | 유지 | 파괴 |    시도 비용 |
| --------- | ---: | ---: | ---: | -----------: |
| 1~5       |  90% |   8% |   2% | 장비 정가10% |
| 6~10      |  70% |  20% |  10% |      정가20% |
| 11~20     |  50% |  35% |  15% |      정가30% |

모든 결과에서 비용 소모. 유지에는 단계 변화가 없고, 파괴에는 해당 장비와 개별 강화값만 삭제하며 기본 장비로 돌아간다. 다른 장비 강화는 남는다. 기본 무료 장비는 강화 불가.

장비 자체 기본 능력치 배율: 0강1배, 1~10강은 매 단계+0.1배로10강2배. 11~20강은 `2 + 3×((강화−10)/10)^1.4`로20강5배. 공격 장비는 공격, 방어 장비는 방어·추가 체력을 강화한다. 춘배 레벨·연애 능력치는 곱하지 않는다. 세일은 강화 비용에 적용하지 않는다.

## 펫스타·펫 Live

스타: 주제16개, 캡션48개, 댓글40개, 피드150개까지 저장하고 더 보기 지원. 올려준 0.366초 MP3 찰칵음을 게시 시 재생한다. 사용 후 메인·분류·프로필을 모두 `남음0/1 · 오늘 완료`로 표시한다. Live는 스타 횟수를 충전하지 않는다.

게시 완료 때10% 확률로 유명 한국인10명·외국인10명 중 한 명의 **게임 속 가상 좋아요** 이벤트. 행복도100, 게시 보상까지 반영된 스타 팬의10% 추가. 이 추가 팬은20% 교차 유입 함수를 호출하지 않는다. 게시물에 결과를 저장하므로 알림 재열기·메뉴 이동·중복 게시 호출로 추가 지급되지 않는다.

Live: 주제12개, 상황24개, 선택지96개. 방송마다 주제별2개+겹치지 않는 추가2개, 총4상황×4선택. 팬 중심·후원 중심·편안한 선택·45% 돌발 도전으로 팬/후원/행복도와 춘배·집사 모션·소품·채팅이 달라진다. 소품은 소모하지 않는다. 300팬부터 협찬, 썸냥이가 있으면 합방 가능. 완주 때만 팬·후원 정산.

일반 획득 팬은 반대 채널에20% 한 번 유입한다. 각 채널 **자기 팬 수**로 배경이 발전: 0 촬영 구석 /100 소품방 /1천 홈 스튜디오 /5천 네온 /3만 스타 방송국 /10만 월드 투어. 현재·다음 해금 인원을 안내한다.

## 날씨·랜덤 이벤트

날씨는 독립적으로 하루10% 비,90% 맑음. 저장·화면 재진입으로 바뀌지 않는다. 비는 집 배경에 표시하며 공원산책을 막는다. 일일 이벤트는 아래 확률로 하루 최대1개, 나머지47%는 평온한 하루. 안내와 기록에 실제 하루 확률을 표시한다.

| 이벤트                                                           |   확률 | 효과                                                               |
| ---------------------------------------------------------------- | -----: | ------------------------------------------------------------------ |
| 택배 / 알고리즘 / 야근 / 세일 / 귀여운 날 / 축제 / 고지서 / 깡패 | 각각5% | 기존 각 효과                                                       |
| 손톱깎이                                                         |     5% | 실행 시 기력−25, 행복도+10                                         |
| 털깎이                                                           |     5% | 실행 시 기력−25, 행복도+10                                         |
| 춘배가 아프다 ㅠㅠ                                               |     1% | 발생 즉시 보유 양수 골드10% 차감, 기력−75, 행복도−75, 한 번만 적용 |
| 냄새가 너무 나! 냥빨을 해야겠어!                                 |     2% | 목욕 실행 시 기력−50, 행복도−10                                    |

기력·행복도 최저0. 마이너스 골드는 질병으로 추가 감소하지 않는다. 행복도0이면 병원. 병원은 레벨별 비용, 부족하면 긴급 대출, 행복도30 회복, 기력 회복 없음.

알고리즘은 획득 팬+30%, 야근은 직접 일당+30%, 세일30% 할인, 귀여운 날 대화·데이트 호감도+30%, 축제 공원 보상+30%와 치즈냥이 만남5%. 고지서는30+레벨×12G 또는 광고, 깡패는80+레벨×35G 또는 기력50.

## 냥서바이벌

1~3단계만 플레이,4~10단계는 개발 중 잠금. 전용 엔딩·크레딧 연결은10단계 개발 때 진행한다. 2400×1800 맵, 카메라·미니맵, WASD/방향키 이동, Space회피, P일시정지, 자동공격, 모바일 방향/드래그 지원.

춘배는4방향×4걷기 프레임, 발걸음·꼬리·공격 반동·피격 반응·회피 잔상으로 표현한다. 무기6종과 보조6종, 경험치 선택·진화. 흡혈은 실제 피해10/20/30%. 큰 체력바, 종류별 증강 색, 큰 획득 아이콘,30px 경험치/44px 특수 아이템. 적 공격·위험 예고는 빨강. 발걸음/무기별/명중/경고/아이템/앰비언스 사운드와 빛·파편·캐스팅 이펙트.

1분 중간 보스,3분 최종 보스. **1스테이지 최종 보스는 날짜와 무관하게 조커의남자 고정**, 잡으면 카지노 해금. 다른 단계 보스는 날짜·장소 순환. 최종 보스 처치로 클리어하며 전투가3분을 넘길 수 있다.

사망·철수에도 부분 보상, 클리어 추가 보상. 골드는 이전 기본 보상의20%, XP는 유지. 치즈폭탄은 주변260범위 일반몹 즉시 처치, 보스 최대체력20% 기준 피해(치명타 적용). 주우면 머리 위 `치즈폭탄!`과 폭발. 3초 단위 저장과 한 번 정산으로 새로고침 중복 지급 방지.

## 연애·성장·경제

치즈냥이 한 종류만 등장. 던전 클리어/근무/스타/Live/힐링 완료마다5%, 이미 관계가 있으면 중복 만남 없음. 재회 대화 후 “너는 이름이 뭐니?”에서 1~12자 이름을 입력한다. 이름·대화 대기 상태는 저장되며 기존 관계는 호감도·단계를 보존한 채 치즈냥이로 이관한다. 대화·선물·데이트 각 하루1회. 고백 전 호감도3, 프로포즈 전6으로 제한. 고백 다이아1, 프로포즈5, 각50% 성공; 실패해도 호감도 감소 없음. 연인/부부/평생 단계, 결혼하면 방에2마리. 평생은 헤어지기 불가.

직장별 주인·직원10단계. 공사장10→회사, 회사10→연구소. 직원 교육은 주인 단계까지만. 직접 일당은 v0.5 대비5배로 상향, 직원 일당·승진 비용은 기존 유지. 근무 중 다른 활동 가능, 다음 날 지급.

수입 배율은 유명세×행복도×연애×집, 주인 일당에 최고 탈것 배율 추가. 행복도70~99는20%,100은50%. 유명세 합100명5%,1천10%,5천15%,1만20%,3만25%,5만30%,10만50%,100만100%.

집8종: 무료/5천/1.5만/4.5만/12만/30만/60만/100만G. 마지막2집은 다이아30/80 추가. 기존 소유 유지. 기상 행복도−10/−5/0/+3/+6/+9/+12/+15. 현재 집만 효과. 차량 붕붕카/냥르쉐/항공은 일당10/15/25% 최고1개, 드라이브 냥르쉐 다이아+1·항공+5.

## v0.6 슬롯 확률·노동 변경

카지노 최소 10G, 보유 골드까지 직접 배팅하며 확인 경고는 없다(안전한 정수 연산 범위 내). 룰렛 배당은 유지한다. 슬롯은 결과별 가중 추첨이며 모든 배당은 원금 포함이다.

| 결과                 |  배당 |   확률 |
| -------------------- | ----: | -----: |
| 황금 왕관 잭팟 3개   | 100배 |  0.01% |
| 777                  |  20배 |  0.20% |
| 춘배 3개             |  10배 |  0.50% |
| 생선 3개             |   7배 |  1.00% |
| 츄르 3개             |   5배 |  2.00% |
| 참치캔 3개           |   4배 |  1.00% |

합계100%, 평균 환급률90%. 추첨된 결과와 실제 릴 그림이 일치하며 잭팟/777 전용 아이콘·효과가 있다.

직접 일하기 보상은 v0.5 대비5배, 직원 수입은 유지. 매 승진마다 새로 필요한 근무일수는 공사장1일/회사2일/츄르연구소3일로 고정하고 승진 시 해당 경력을 소비한다. 총 누적 근무일수는 별도로 유지한다. 기존 경력은 이관 시 한 번만 다음 승진 필요량까지 인정한다. 승진 비용과 직장·직원 단계 해금은 유지한다.

춘배 이동 시트는 방향별 실제 그림 경계로 잘라 그려 인접 프레임의 발이 섞이거나 발끝이 잘리는 것을 수정했다.
