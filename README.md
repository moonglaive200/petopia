# Petopia 0.4.10 · 춘배와 집사의 이상한 하루

HTML/CSS/JavaScript로 실행되는 저장형 브라우저 게임. 온라인 랭킹과 서버 계정은 사용하지 않는다.

## 실행과 저장

```sh
cd /workspace/petopia
python -m http.server 8000
```

정적 서버 또는 GitHub Pages의 `main` 브랜치 루트에서 실행한다. 모든 이미지·폰트·음원은 저장소에 포함되어 있다. 저장은 현재 브라우저/주소의 localStorage에 보관되며 설정에서 JSON 내보내기/가져오기가 가능하다.

신규 시작 순서: **시작하기 → 슬롯 → 집사 이름 → 춘배 선택 → 풀숲에서의 첫 만남 → 메인 화면**. 저장 슬롯 3개는 독립적이며 삭제 전 재확인한다. 오레오는 개발 중으로 잠겨 있다. 기존 저장의 돈·이름·아이템·자산을 유지하면서 v3 상태로 확장한다. 기존 슬롯에서는 도입부를 강제로 재생하지 않는다.

## 하루와 주인 기력

기력은 **주인 기력 하나**, 최대 100. 당일에는 병원·아이템·시간 경과로 회복되지 않는다. 주인 기력 25 이하에서 하단 **잠자기**로 다음 날이 되면 100으로 초기화한다.

| 활동                             | 일일 제한                        |               주인 기력 |
| -------------------------------- | -------------------------------- | ----------------------: |
| 냥서바이벌                       | 하루 1회                         |                      50 |
| 유흥                             | 하루 1회                         |                      25 |
| 주인 일하기                      | 하루 1회, 다음 날 일당 정산      |                      50 |
| 인플루언서냥                     | 펫스타 하루 1회 / Live 3일에 1회 | 그날 첫 활동 25, 이후 0 |
| 연애 / 인벤토리 / 상점·은행·병원 | 행동별 제한                      |                       0 |

인플루언서 메뉴 구경은 무료다. 펫스타와 Live를 모두 하는 날도 합계 25만 사용한다. 메인 화면은 펫마트·펫은행을 포함한 2칸×4줄이고, 하단 보조 메뉴는 병원·잠자기·설정 3개다.

잠자기는 확인창 없이 잠드는 장면 후 다음 날 정산으로 연결된다. 큰 4칸에 전날 획득 금화·다이아·팬 변화·호감도 변화를, 아래에는 순잔액 변화·시작 기력·행복도·재입고·대출 내역을 표시한다. 판매·대출은 활동 획득 금화와 분리한다. 카지노는 총 지급액을 획득으로 기록한다.

달력은 봄·여름·가을·겨울 각 28일, 112일이 1년. 1일은 일요일이며 토·일을 표시한다. 상단 `SPRING 1 (일) 📅` 아이콘으로 28칸 달력을 연다. 춘배 생일은 WINTER 27. 일일 기록은 날짜를 먼저 붙여 3줄 높이 스크롤로 보관한다.

## 냥서바이벌

- 세 모드 랜덤 방식과 별도 보스 메뉴를 없애고 **냥서바이벌 하나**로 통합.
- 10단계 중 1~3단계만 플레이 가능, 4~10단계는 개발 중으로 잠금. 10단계 전용 엔딩·엔딩 크레딧 연결은 후속 작업으로 보류. 장소 3개: 햇살 공원 / 버려진 펫마트 / 네온 뒷골목. 넓은 2400×1800 맵, 추적 카메라와 미니맵.
- **01:00 중간 보스 / 03:00 최종 보스**. 최종 보스를 처치하면 클리어하며, 보스 전투 시간이 추가될 수 있다.
- WASD/방향키 이동, Space 회피, P 일시정지. 자동 공격. 모바일 방향 버튼과 드래그 이동 지원. 탭을 벗어나면 자동 일시정지.
- 몬스터 12종, 추격·원거리·돌진과 보스 탄막·장판·회복 패턴. 보스 10종은 장소와 게임 날짜에 따라 순환한다.
- 무기 6종: 냥발톱 / 생선 / 방울 / 털실공 / 레이저 / 츄르 웅덩이. 보조 능력 6종. 발톱·생선·방울·털실·레이저·캔 모양의 경험치 아이템으로 레벨업할 때 3개 중 선택. 선택 중에는 전투가 멈춘다.
- 무기 5단계와 대응 보조 능력 3단계를 갖추면 진화. 판 안의 성장은 초기화되고, 펫 레벨·장비·발견 기록은 유지된다.
- 체력은 상단 큰 바와 숫자, 획득 증강은 하단 큰 아이콘·단계로 표시한다. 선택 카드는 무기/공격/범위/속도/피흡/회수/행운별 색상. 방어 증강을 흡혈 송곳니로 교체: 실제 준 피해의 10%/20%/30% 회복, 최대 체력 제한.
- 피격 번쩍임, 넉백, 히트스톱, 화면 흔들림, 피해 숫자, 발톱 궤적·탄환·처치 파편과 타격음.
- 사망해도 생존 시간·처치·보스 보상 정산. 클리어 추가 보상. 사망과 승리에 서로 다른 효과음.
- 3초마다 진행을 저장한다. 새로고침으로 중단된 전투도 마지막 저장 시점의 진행 보상을 한 번 정산하고 병원으로 보낸다. 직접 철수는 부분 보상을 받고 귀가한다. 입장 기력과 횟수는 반환되지 않는다.
- 조커의남자 처치 시 카지노 해금. 랭킹은 없고 최근 개인 탐험 내역만 보여준다.

## 연애

썸냥이 3종: **치즈냥이 / 턱시도냥이 / 백설냥이**. 처음에는 비어 있고 획득 방법을 보여준다.

활동 완료 시 만남 판정: 던전 **클리어** 1%, 산책 3%, 주인 근무 정산 1%, Live 정산 1%, 펫스타 게시 1%. 기존 공원의 20% 만남 이벤트는 삭제했다. 비게 된 확률은 평범한 산책에 합쳐 평범한 산책 80% / 장난감 5% / 츄르 5% / 쓰다듬 10%다. 만남 판정은 해당 이벤트와 별도다. 비는 하루 날씨(10%)와 공유하며 공원 방문 시 행복도 −12가 추가된다.

- 대화: 무료, 하루 1회, 호감도 +0.15.
- 츄르 또는 장난감 선물: 종류 합산 하루 1개. 실제 보관함 수량 차감.
- 데이트: 하루 1회. 벤치 450G/+0.2, 맛집 1,950G/+0.5, 루프탑 5,400G/+1.
- 장난감은 호감도 1당 3,000G 비율(600~2,760G), 추가 다이아 없음. 츄르는 행복도·취향을 고려해 참치400G/+0.15, 연어1,100G/+0.35, 금수저2,200G+다이아1/+0.7. 선호 츄르는 ×1.4.
- **호감도 3**: 고백. 다이아 1개, 성공률 50%. 성공 전 호감도 3 제한.
- **호감도 6**: 프로포즈. 다이아 5개, 성공률 50%. 성공 전 호감도 6 제한.
- 실패해도 호감도는 내려가지 않으며 고백/프로포즈 자체는 호감도를 추가하지 않는다.
- 연인냥이: 활동 금화 +8%, 공격 +1, 방어 +1.
- 부부냥이: 활동 금화 +15%, 공격 +3, 방어 +2, 매일 20 G. 방에 춘배와 배우자 두 마리 표시.
- 호감도 10, 평생의 냥: 활동 금화 +30%, 공격 +6, 방어 +4, 매일 50 G와 참치 츄르.
- 다른 냥이를 만나면 갈아타기 가능, 새 관계는 호감도 0부터. 썸/연인은 헤어지기, 부부는 이혼하기. 평생의 냥은 관계 종료·갈아타기 불가.

## 펫마트·인벤토리

- 장비: 무기 10단계/방어구 10단계(기존 3종 인덱스 유지), 부위별 +10까지 확정 강화. 펫대장간 안 공격장비/방어장비/장난감 버튼으로 분류.
- 장난감: 10종, 호감도에 비례한 가격. 행복도를 올리지 않고 선물로 호감도를 올린다. 중복 구매·뽑기 획득은 수량으로 저장.
- 참치 츄르 **400 G**, 연어 **1,100 G**, 금수저 **2,200 G + 다이아 1**. 종류별 매일 0~2개 입고, 화면을 다시 열어도 재고는 바뀌지 않는다.
- 내 펫에게 츄르 **먹이기 하루 1개**, 썸냥이에게 **선물 하루 1개**는 독립 제한.
- 차량 금화 가격 10배: 붕붕카 5,000 G / 냥르쉐 24,000 G / 츄르항공 300,000 G. 냥르쉐 드라이브 다이아 +1, 항공 +5. 주인 일당 +10%/+15%/+25%. 차량 일당 효과는 최고 하나만 적용.
- 자동차 소유와 썸냥이 만남 두 조건을 충족해야 드라이브 해금. 호감도 +0.1. 비행기만으로 자동차 해금 조건을 대신하지는 않는다.

## 근무·집·투자

직접 일하는 중에도 다른 콘텐츠 이용 가능. 공사장·회사·연구소별 출근 컷신. 주인과 직원은 각각 일터별 10단계.

- 주인 승진: 누적 근무 일수 + 기존 대비 10배 금화 교육비. 직접 일당은 기존 2배. 공사장10단계→회사, 회사10단계→연구소 해금.
- 직원: 고용 비용은 기존 10배, 일당은 기존 5배. 금화로 교육하며 주인의 같은 직장 단계까지만 가능.
- 빌딩은 9종·매일 가격의 2%, 회사는 매일 인수가격의 1%, 집 일당 효과는 유지.
- 인수한 회사는 인수가격의 1% 수입에 더해 매일 **해당 회사 주식 1주** 지급.
- 주식 전일 대비 **−30%~+30%**, 코인 **−99%~+200%**. 매도 수수료 4%. 종목 가격이 1G 이하가 되면 거래 정지, 다음 날 보유분 전량 소멸(보상 없음), 발생일로부터 3일 뒤 기본가격 재상장. 개인 매입가 대비 손실률은 상장폐지 조건이 아니다. 평균원가·실현손익·전일대비를 보관하고 은행 첫 화면에 포트폴리오를 표시한다. 기존 보유분 원가는 업데이트 시점 가격, 회사 지급 주식 원가는 지급 시점 가격으로 기록한다. 회사·주가는 실제 기업들의 상대 규모를 참고한 가상의 게임 가격이다.
- 집별 기상 행복도: 집사랑 노숙 중 −10 / 택배 상자 −5 / 반지하 0 / 아파트 +3 / 풀빌라 +6 / 저택 +9 / 우주 펫하우스 +12 / 천상궁전 +15. 기존 공통 기상 감소를 대체한다.
- 대출 한도는 100+(레벨−1)×75G. 5일 후 원금의 150%를 정상 상환하며, 부족하면 원금의 200%를 한 번 차감해 마이너스 잔액으로 처리한 뒤 종료한다. 추가 이자는 없다. 만기 전 조기 상환의 이자 면제와 병원 긴급 대출 한도 예외는 유지한다.
- 병원은 레벨별 치료비와 긴급 대출을 지원하고 행복도를 **30**으로 회복하되 **주인 기력을 회복하지 않는다**.

## 방송·연출·기존 오락실

춘배와 썸냥이 3종에 기본/잠자기/행복/놀람/슬픔 표정 적용. 펫스타 게시 시 셔터음. Live 선택 시 춘배 움직임, 발바닥 줌, 집사 등장·춤, 잠자기 연출. Live→펫스타 / 펫스타→Live 직접 팔로워 20% 유입, 재귀 유입 없음.

방앗간 뽑기는 선물이 210~265px/s로 빠르게 좌우 왕복하며 집게가 바닥에 도착한 순간 ±6 안이면 성공한다. 냥냥비트는 개발 중으로 잠근다. 고양이 HEX는 실제 게임오버 후 내부 복귀와 외부 복귀 버튼을 지원한다. 카지노는 냥슬롯·냥룰렛. 산책 입장의 25 기력 외에 미니게임 추가 기력은 없다. 금화 참가비는 그대로. 다이아는 산책·미니게임에서만 획득한다. 카지노는 금화만 사용한다.

로비 배경은 제공된 마을 이미지, 글자 받침과 나무 버튼. 인게임은 나무·양피지 색감과 높은 글자 대비로 개편했다. 효과음·배경 움직임 설정 및 백업 기능 유지. 출처는 [ASSETS.md](ASSETS.md).

## 수입 보너스와 하루 이벤트

수입 배율 = 유명세 × 행복도 × 연애 × 현재 집. 주인 일당에는 최고 탈것 한 개의 배율을 추가로 곱한다. 고정 빌딩·회사·동반자 생활 선물은 안내한 고정액을 지급한다. 메인 6칸 상태창에서 일반 수입 보너스와 주인 일당 보너스를 구분해 표시한다.

유명세(두 채널 합): 100명5%, 1천10%, 5천15%, 1만20%, 3만25%, 5만30%, 10만50%, 100만100%. 행복도70~99는20%, 100은50%.

비는 하루 시작10%, 일일 이벤트는40% 확률로 다음8종 중 하나. 하루를 다시 열어도 바뀌지 않는다. 비는 집 배경과 공원 상황에 함께 반영된다.

- 택배: 열면75%로 참치 츄르, 나머지는 빈 상자.
- 알고리즘: 획득 팬30% 증가(20% 교차 유입은 증가된 팬 기준).
- 야근: 직접 일당30% 증가.
- 세일: 펫마트 상품30% 할인, 강화 교육비는 제외.
- 귀여운 날: 대화·데이트 호감도30% 증가.

치즈폭탄은 두툼한 삼각형 치즈 모양이며 주우면 머리 위에 ‘치즈폭탄!’이 뜬다. 일반 몬스터 처치 시 드물게 떨어진다. 획득 즉시 주변 260 범위의 일반 몬스터를 처치하고 보스에게 최대 체력 20% 기준 피해(치명타 적용)를 준다. 범위 밖 적은 유지된다. 적 탄환·위험 장판·돌진 예고는 빨간색, 경험치 아이템은 30px, 특수 아이템은 44px로 표시한다. 증강창은 데스크톱 가로 3칸, 모바일 세로 카드와 내부 스크롤을 지원한다.

주인 일하기 메뉴 이름은 ‘주인 노동시키기’. 인형뽑기는 집게 접촉 순간 중심 ±6px 판정으로 CATCH!/fail..을 표시하며, 성공에는 큰 글자·별빛·상승 음계, 실패에는 어두운 화면·하강 음계를 사용한다.

냥서바이벌의 시간·처치·보스·필드 골드·클리어 골드 전체를 기존의 20%로 줄이며, 수입 배율을 적용한 뒤 소수점을 버린다. 경험치 보상은 유지한다. 백설냥이는 기존 흰색냥이와 같은 캐릭터 인덱스를 사용해 저장된 관계를 유지한다.

거래 정지 중에는 매수·매도를 모두 막고 해당 회사의 주식 지급도 보류한다(고정 운영 수입은 유지). 재상장 후 과거 보유분은 복원되지 않으며 새 매수 및 일일 지급이 다시 가능하다. 상장폐지·재상장 예정일은 투자 목록·포트폴리오·날짜별 기록·다음 날 정산에 표시한다.

일일 변동률을 적용한 가격은 1G 단위로 반올림하므로 저가 구간에서는 표시 등락률에 반올림 차이가 생길 수 있다. 이 규칙으로 주식도 자연 하락 중 1G에 도달해 상장폐지 절차에 들어갈 수 있다.

빌딩은 기존 세 종류 인덱스를 유지한 9종이며 가격은 18,000/48,000/130,000/180,000/260,000/380,000/540,000/740,000/1,000,000G. 매일 가격의 2%를 지급한다. 회사는 각 인수가격의 1%를 고정 운영 수입으로 지급하며 해당 주식 1주도 지급한다(거래 정지 기간에는 주식만 보류). 잠자기는 UI와 날짜 전환 규칙 모두 주인 기력 25 이하에서만 허용한다.

집은 8종이며 가격은 무료/5,000/15,000/45,000/120,000/300,000/600,000/1,000,000G. 우주 펫하우스는 다이아30, 새 춘배의 천상궁전은 다이아80을 추가로 사용한다. 기존 구매한 집은 유지하며 다시 선택할 때 금화·다이아를 청구하지 않는다. 천상궁전은 기상 행복도+15, 일반 수입×1.5, 직원 추가×1.3, 고용비25% 할인이다.
